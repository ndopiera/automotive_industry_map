# Markersymbole

- `colors.py`: Farbpalette und automatische Farben neuer Kategorien.
- `pictograms.py`: Piktogramme je Hauptkategorie.
- `renderer.py`: PNG-Erstellung, Farbsegmente und Symbol-URLs.
- `__init__.py`: Schnittstelle zum Export.

Der Export erzeugt die PNG-Dateien in `public/icons/`. Die URLs und Dateinamen bleiben unverändert.
